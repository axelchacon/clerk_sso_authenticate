
🚀 Proyecto Backend - Configuración y Ejecución

📄 Archivo `.env` requerido

Crea un archivo `.env` en la caroeta Back del proyecto con el siguiente contenido:

PORT=3000
MONGO_URI=mongodb://localhost:27017/usuarios

> Asegúrate de que MongoDB esté corriendo en tu máquina local.

------------------------------

▶️ Cómo ejecutar el servidor

Desde la raíz del proyecto, corre:

node server.js

------------------------------

✅ Requisitos

- Node.js instalado
- MongoDB en funcionamiento localmente
